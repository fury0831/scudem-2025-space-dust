Viewing guide / 查看说明

  • Use the velocity slider and legend to compare curves. If a previous axis range clips the next frame, select Reset axes in the toolbar. / 用速度滑块和图例比较曲线；切换后若范围不合适，点击工具栏的 Reset axes。
  • The original files start their saved animation after loading. A desktop browser is recommended: each chart uses a fixed 900 × 600 layout and embeds more than half a million points. / 原文件加载后会自动播放已保存动画；图表为固定 900 × 600 布局，内嵌超过五十万个点，建议使用桌面浏览器。
  • Initial velocities: 6–68 km/s in 2 km/s steps; radii: 0.001–100 μm. Records extend up to 100 s, but some end earlier without a saved reason. / 初速度为 6–68 km/s、间隔 2 km/s，半径为 0.001–100 μm。最长记录到 100 s，部分更早结束且未保存原因。
  • The HTML velocity values are nonnegative, unlike an older report plot. The frame-generating solver is not included, so version equivalence is unverified. Zero values and early endpoints alone do not establish physical outcomes. / HTML 的速度数据非负，与旧报告的一张图不同。未附生成这些帧的求解器，尚不能确认版本一致；仅凭零值和提前终点不能判断物理结果。
